## تنظیم اتصال Supabase

فایل `.env.example` را به `.env.local` کپی کنید و مقدار Project URL و Publishable Key را از Supabase وارد کنید. نام‌های پشتیبانی‌شده:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` (یا کلید قدیمی `NEXT_PUBLIC_SUPABASE_ANON_KEY`)

در Vercel نیز همین متغیرها را در Settings → Environment Variables برای محیط‌های Production و Preview ثبت کنید و سپس Redeploy بزنید. کلید `service_role` یا `secret` را در متغیر `NEXT_PUBLIC_` قرار ندهید.
